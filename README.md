# Assignment 3: Kubernetes Orchestration & Full DevOps Pipeline

## Overview
3-tier microservice application: Nginx → Flask API → MySQL
Deployed using Docker Compose and Kubernetes (Minikube)

## Architecture
- Nginx: Reverse proxy (Port 80)
- Flask API: REST API backend (Port 5000)
- MySQL: Database (Port 3306)

## Quick Start
```bash
chmod +x start.sh
./start.sh
```

## Parts
- Part A: Git & Version Control
- Part B: Docker containerization
- Part C: CI/CD with GitHub Actions
- Part D: Kubernetes on Minikube
